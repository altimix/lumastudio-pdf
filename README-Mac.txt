LumaStudio PDF — Mac版のインストールと初回起動

1. 自分のMacに合ったファイルを選びます

Appleメニュー →「このMacについて」を開きます。
「チップ」がM1、M2などのApple Siliconなら、ファイル名に arm64 がある版。
「プロセッサ」がIntelなら、ファイル名に x64 がある版を選んでください。
配布元: https://github.com/altimix/lumastudio-pdf/releases

2. アプリケーションフォルダーに入れます

DMG版: ダウンロードした .dmg を開き、LumaStudio PDF.app を「Applications」へドラッグします。
ZIP版: ダウンロードした .zip をダブルクリックして展開し、LumaStudio PDF.app を「アプリケーション」へ移します。
Node.jsを入れたり、ターミナルでコマンドを実行したりする必要はありません。

3. 初回の警告が出たとき

この試用版には、アプリの整合性を確認するためのアドホック署名があります。
AppleのDeveloper ID署名・公証はないため、初回は開発元を確認できない旨の警告が出る場合があります。
配布元とダウンロードしたファイルを確認したうえで、LumaStudio PDFだけを許可する手順です。

・「アプリケーション」から LumaStudio PDF を一度開いてみます。
・開発元・Appleによる確認についての警告が出たら、その警告を閉じます。
・Appleメニュー →「システム設定」→「プライバシーとセキュリティ」を開きます。
・「セキュリティ」付近にある LumaStudio PDF の項目で「このまま開く」を選びます。
  macOSのバージョンによっては、先に「開く」を選ぶ画面になります。
・画面の案内に沿ってログインパスワード等で認証し、開くことを確認します。

通常、この項目は起動を試してから約1時間表示されます。表示されないときは、もう一度アプリを開いてから設定を確認してください。
許可されたアプリは、以後は通常のダブルクリックで開けます。更新時などに再確認される場合があります。
Mac全体の保護を無効にしたり、隔離属性を削除したりするコマンドは不要です。

「コンピュータに損害を与える」「破損している」などの警告は、この手順の対象ではありません。
その場合は操作を止め、警告の全文とMacの種類・macOSのバージョンを開発者へお知らせください。
会社や学校が管理するMacで許可できない場合は、端末の管理者に相談してください。
すべてのMacで起動が許可されることを保証する手順ではありません。

Apple公式の説明:
https://support.apple.com/ja-jp/guide/mac-help/mh40616/mac

4. 最初の操作

起動後は「サンプルの書類で試す」で、文字の記入や印鑑の配置を練習できます。
相手へ送る完成版は「PDFを保存」、あとで修正するためのデータは「作業データを保存」で残してください。
AIを使う場合は「AI設定」に自分のAPIキーを登録します。通常の記入・保存にはAPIキーは不要です。
証明書によるPDFへの署名は、上部の「証明書ガイド」を参照してください。アプリの署名とは別の証明書です。

検証の範囲

CIで配布ZIPを展開し、アプリの署名構造とリソースの整合性を確認します。
CI上のホストCPUに対応したアプリで、起動とサンプルPDFの表示も確認します。
これはAppleの公証、すべてのMacでの動作確認、ダウンロード直後の警告画面の実機確認を意味しません。
配布物のSHA-256は、ReleaseのSHA256SUMS.txtに記載します。
