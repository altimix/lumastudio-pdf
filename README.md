# LumaStudio PDF

届いたPDFに文字や口座情報を記入し、画像の印鑑を押して返送するための、Windows・macOS向けデスクトップアプリです。動画編集ソフト「Luma Studio」と同じLumaStudioシリーズです。

公式サイト: [lumastudiopdf.altimix.jp](https://lumastudiopdf.altimix.jp/)

通常編集とAI実行時のデータの扱いは[公式サイトの説明](https://lumastudiopdf.altimix.jp/privacy/)を参照してください。

使い方などのお問い合わせは [株式会社Altimixの共通窓口](https://altimix.co.jp/contact/) へ。不具合や機能提案は [GitHub Issues](https://github.com/altimix/lumastudio-pdf/issues) でも受け付けます。公開Issueに実際のPDF、印影、秘密鍵、APIキーを添付しないでください。

## ダウンロードして使う

[GitHub Releases](https://github.com/altimix/lumastudio-pdf/releases) から、WindowsならポータブルEXE、Macならご自身のCPUに合うZIP（Intel／Apple Silicon）を選びます。WindowsはダウンロードしたEXEを起動し、MacはZIPを展開してアプリを「アプリケーション」へ移します。Node.jsは不要です。更新時は新しい配布ファイルへ手動で入れ替えます。印鑑・プロフィール・AI設定はOSの利用者データ領域に保存され、EXEやZIPを削除しても自動では消えません。

Mac版はDeveloper ID署名・Apple公証を使わず、整合性確認用のアドホック署名を付けて配布します。開発元を確認できない警告が出た場合は、配布元を確認してから **システム設定 → プライバシーとセキュリティ → LumaStudio PDF の「このまま開く」** でアプリを個別に許可します。初回の詳しい手順は、ZIPとReleaseに同梱する [Mac版の起動案内](README-Mac.txt) を参照してください。許可画面の表示や起動は、端末の管理設定にも依存します。[Apple公式の説明](https://support.apple.com/ja-jp/guide/mac-help/mh40616/mac)

証明書をまだ持っていない場合は、アプリ上部の **証明書ガイド** または「署名して保存」内の **証明書を持っていない方へ** を開いてください。取得先への確認、個人／会社の公式窓口、必要な形式、入手後の読み込みまで案内します。証明書がなくても通常の編集と印影の配置は利用できます。

## 開発環境で起動

Node.js 22.12以降とnpmが必要です。

```sh
npm ci
npm run desktop
```

この作業フォルダーでは `Start LumaStudio PDF.cmd` をダブルクリックしても起動できます。Windows用のビルドがある場合はそれを使い、プロジェクトの `.env` をAI設定として読み込みます。APIキーを実行ファイルに埋め込むことはありません。

開発中のデスクトップ版は `npm run desktop:dev`。ブラウザーで試す場合は `npm run dev` を実行し、`http://127.0.0.1:5193` を開きます。ブラウザー版でもPDFの記入・保存・AI候補の生成を確認できます。印刷受信箱とネイティブ保存はデスクトップ版の機能です。

Electronランタイムがnpmのスクリプト実行制限で取得されなかった場合は、`node node_modules/electron/install.js` を実行してください。

## できること

- PDFを開く／ドラッグで取り込む。架空の振込先届出書サンプルで試す。
- パスワードを知っているPDF、閲覧可能な編集制限付きPDF、署名済みPDFから、元ファイルを残して画像ベースの編集用コピーを作成。元の署名や文字検索等は引き継がない。
- 日本語の文字、日付、チェック、PNG/JPEG画像を好きな場所へ追加。
- PDF上をクリックして直接入力、追加した文字はダブルクリックで再編集。文字の初期色は黒（RGB 0, 0, 0）。
- 2本指のピンチで20〜400%に拡大縮小。手のひらツール、幅に合わせる／ページ全体表示で用紙を見やすく移動。
- 印影画像の背景透過、複数の印鑑の登録と切り替え。丸印・角印の簡易作成も可能。
- 追加した文字・印影の移動、内容・サイズ・色の修正、複製、削除、元に戻す／やり直す。
- 複数のPDFを1つに結合。結合前のファイル順もドラッグで変更可能。
- ページ一覧のサムネイルをドラッグして並べ替え。右クリックから指定ページを削除し、元に戻す／やり直すことも可能。
- ページを右クリックして、その1ページだけをPDFに保存。ページの回転にも対応。
- 作業データ（`.lumapdf`）に保存し、後日文字・印鑑を選んで編集を再開。
- 記入済みPDFを別名保存し、メールへ添付できる状態にする。
- デスクトップ版でRSAのP12/PFX証明書を読み込み、内容確認後に「署名して保存」。証明書の有効期限・秘密鍵との一致を確認してから署名する。
- 編集結果の印刷。デスクトップ版はOSの印刷画面へ渡す。
- よく使う氏名・住所・口座情報を端末に登録。
- AIで表示中のページの記入欄を読み取り、登録情報・選択した印鑑の配置候補を作成。利用者が候補を選んで配置し、通常の要素として修正可能。

保護されたPDFの編集用コピーの条件と、コピーに残らない情報は [保護PDFの扱い](docs/protected-pdfs.md) にまとめています。

## 用紙上での記入とサイズ変更

新しい文字の初期設定は **Noto Sans JP・11pt・黒**、印鑑は **35×35pt**、チェックは **15×15pt** です。画像の印影は縦横比を保って35pt四方に収めます。チェックと図形はクリック位置を中心に、文字は縦方向の中心をクリック位置に合わせます（文字の左端はクリック位置）。

「フォント」から Noto Sans JP、Noto Serif JP、M PLUS 1、BIZ UDGothic を選び、太字・斜体・下線を設定できます。書体はアプリに同梱しており、インターネットがなくても編集とPDF保存に使えます。旧作業データは従来書体で開きます。[フォントとライセンスの説明](docs/fonts.md)

数値欄は空欄にしてから打ち直せます。Enterまたは欄の外へ移動すると確定し、Escで取り消します。数値欄の上でマウスを左右にドラッグしても調整でき、Shiftで大きく、Altで細かく変わります。ドラッグ中はプレビューし、マウスを離した時に1回の変更として保存します。

「図形」は丸が初期選択です。長方形・楕円／円・三角形・線・二重線（取消線）も選べます。枠線と塗りつぶしの色、表示の有無、枠線幅を指定し、辺や角をドラッグして伸縮できます。線と二重線には塗りつぶしがなく、枠線の色と太さを使います。

**文字を記入 → 用紙の記入欄をクリック** すると、その場に入力欄が開きます。Enterで改行、**完了** または **Ctrl / ⌘ + Enter** で確定、Escで取り消します。日本語変換中のEnterやEscは変換操作を優先します。右側で先に文字を用意してから配置する従来の使い方もできます。

追加した文字をダブルクリック（キーボードでは選択してEnter）すると、内容を直接修正できます。既存の追加文字をすべて消して確定すると、その文字要素を削除します。「元に戻す」で復元できます。入力中にPDFを保存した場合も、入力内容を確定して書き出します。最初からPDFに含まれている本文の書き換えは対象外です。

文字・印鑑・画像・チェック・図形を選択すると、**縦横比のロック** を切り替えられます。ロック中は四隅をドラッグすると比率を保ち、解除すると辺や角から縦横を別々に伸縮できます。幅・高さの数値入力もロックに従います。文字は比率を保つ変更で文字サイズも一緒に変わります。選択した素材は矢印キーで1ポイントずつ、Shift＋矢印キーで10ポイントずつ移動できます。移動・リサイズ・直接入力の確定は、1回の「元に戻す」で取り消せます。

トラックパッドやタッチ画面の2本指でピンチすると、PDFだけが拡大縮小します。Ctrl＋マウスホイールでも操作できます。**手のひら・スクロール** ツール、Spaceを押しながらドラッグ、マウス中ボタンドラッグで表示位置を移動できます。入力欄やボタンにフォーカスがある場合、Spaceはその項目の操作を優先します。

## AI機能

基本の編集・保存は端末内で完結します。AIを実行したときだけ、ページ画像と登録情報をOpenAIへ送信します。印影を含む記入済みページを送る場合、その見えている内容も画像に含まれます。生成した候補は保存前に必ず確認してください。

デスクトップ版は上部の **AI設定** からAPIキーを登録できます。AIモデルはGPT-6 Sol（初期値）またはGPT-6 Lunaを選べます。保存済みのキーを入力し直さずにモデルだけ変更でき、選択は次回起動にも引き継ぎます。キーはOSの保管機能で暗号化し、この端末に保存します。保存済みのキーは画面へ戻しません。保存したAI設定を削除すると既存の環境設定に戻ります。OSの保管機能を利用できない場合は、平文保存せず登録を停止します。

従来の設定ファイルも使えます。開発時はプロジェクト直下の `.env`、配布版はElectronのユーザーデータフォルダーの `.env` を読み込みます。アプリ内で保存した設定が優先され、`LUMA_ENV_PATH` で設定ファイルの場所を指定できます。キーはPDF・作業データ・配布物に含めません。

```dotenv
OPENAI_API_KEY=your-api-key
```

AIを使わない場合はAPIキー不要です。詳しくは [AI機能の説明](docs/ai.md)。

## PDFの結合・並べ替え・削除

上部の **PDFを結合** から複数ファイルを選び、表示されたファイルをドラッグして順番を調整し、**この順序で結合** を押します。PDFを開いている場合は末尾へ追加され、記入済みの文字や印鑑も編集可能なまま残ります。結合後は左のページ一覧でさらにページをドラッグして並べ替えられます。

削除したいページのサムネイルを **右クリック → このページを削除** で削除します。Macの副ボタンクリックにも対応し、サムネイルの「…」ボタンやShift+F10でも同じメニューを開けます。最後の1ページは削除できません。削除・結合・並べ替えは **元に戻す** で取り消せます。

完成したら **PDFを保存**。1ページだけ必要な場合は **右クリック → このページをPDF保存** を使います。元のファイルは、保存画面で明示的に上書きしない限り変更しません。署名付きPDFの結合・並べ替え・削除は、署名を失わないため無効です。

結合は1回30ファイルまで、結合元の合計50MB・200ページまでです。取り消し・復元に使う元ページも内部で保持するため、大量に削除した後で制限に達する場合は、必要なページだけPDF保存して開き直してください。

## 編集を後日再開する

v0.3.0は旧形式の作業データも読み込めます。新しく保存する作業データは、書体・装飾・図形の指定を守るため形式バージョン2となり、v0.3.0以降で開いてください。完成したPDFは通常のPDFビューアーで開けます。

上部の **作業データ → 作業データを保存** で `.lumapdf` を保存します。PDFの元データ、現在のページ順・回転、配置した文字・チェック・印影画像を含みます。**保存した作業データを開く** または `.lumapdf` を画面へドラッグして、編集を再開できます。保存時点の状態を復元し、その前の取り消し履歴は含みません。

作業データはこのアプリ専用です。相手へ返送するファイルは **PDFを保存** で書き出してください。作業データには、その書類へ配置した情報だけが含まれ、未使用のプロフィール・印鑑ライブラリー・APIキー・署名用証明書は含まれません。最大100MB、記入・印鑑等は2000個までです。

## ほかのアプリから印刷して取り込む

Windowsでは既存のMicrosoft Print To PDFドライバーを使って「LumaStudio PDF」という印刷先を追加する任意スクリプトを用意しています。アプリ起動中に印刷すると、専用受信箱のPDFを開きます。管理者として実行するセットアップが別途必要です。固定ファイルへ出力するMVP方式のため、1件ずつ印刷して取り込みを待ってください。

Macでは、インストールしたアプリを「PDFサービス」に登録し、ほかのアプリの印刷画面にある「PDF」メニューから渡します。Windowsと同じ仮想プリンタードライバーをMacに入れる方式ではありません。

セットアップ、削除手順、制約は [印刷連携の説明](docs/printing.md)。OS統合スクリプトは自動実行しません。

## 証明書を使う電子署名

印影画像と暗号学的な電子署名は別のものです。必要事項の記入と押印を済ませてから「署名して保存」を使います。署名用の証明書（秘密鍵を含む `.p12` / `.pfx`、RSA 2048ビット以上）とパスワードが必要です。秘密鍵は画面へ渡さず、パスワードは保存しません。署名済みPDFは必ず別名の新規ファイルとして保存します。

テストでは開発用の自己署名証明書を使用します。これは実在の本人確認や認証局の保証を与えません。本番での利用には利用者の証明書と、受信者側での信頼確認が必要です。印影画像のコピー自体を禁止する機能ではありません。署名付きPDFを再度開く場合は閲覧専用とし、アプリ内では署名の有効性を検証済みと表示しません。

MVPは基本のPDF署名に対応します。外部タイムスタンプ（TSA）、失効情報の取得、長期検証情報の埋め込み、ICカード・ハードウェアトークンは未対応です。[証明書署名の仕様](docs/signatures.md) を参照してください。

## 配布用ビルド

各OSでビルドしてください。WindowsではWindows版、MacではMac版を作成します。

```sh
npm run package:win
npm run package:mac
```

出力先は `release/`。MacのIntel / Apple Siliconを両方作成する場合は `npm run build` の後に `npx electron-builder --mac zip --x64 --arm64 --publish never`。Windowsは発行元コード署名なし、Macはアドホック署名のみでAppleの公証はありません。OSによる起動確認が表示される場合があります。

GitHubの`main`へのpushとPull Requestでは、Windows・macOSの両方で単体テスト、本番ビルド、ブラウザー操作テスト、配布アプリの起動確認を実行します。成功した実行のActions画面から、`LumaStudio-PDF-Windows`／`LumaStudio-PDF-macOS`の成果物を取得できます。

## 対応範囲と制約

- 元PDFへ追加する方式です。既存本文の文字の置換、OCRでの文書再構成には未対応です。
- パスワード付きPDFは開くパスワードが分かる場合だけ編集用コピーに変換できます。XFAフォームには対応していません。
- 追加文字は日本語の見た目を揃えるため画像として保存します。追加文字の検索・選択はできません。元PDFの本文・線は原則保持します。
- 書き出し時にフォームの表示も固定します。完成PDFには追加要素を個別編集する情報は残りません。後日修正する場合は、あわせて `.lumapdf` の作業データを保存してください。
- プロフィールと登録印鑑はアプリ内の端末保存領域に保存します。共有端末ではアプリから消去できます。暗号化された保管庫機能はありません。
- 読み込みは50MBまで。大きなPDF・複雑なPDFでは、メモリー使用量が増えます。
- Windowsの物理印刷と専用プリンター登録、Mac実機での起動とPDFサービス連携は、対象機での追加確認が必要です。

## 検証

```sh
npm test
npm run build
# npm run dev を別のターミナルで起動してから
npm run test:e2e
# WindowsのElectron本体で、隔離した検証用データを使用
node scripts/smoke-desktop.mjs
```

E2Eはインストール済みChromeを使います。通常テストはAI接続をモックし、OpenAIへ文書を送信しません。実API検証は `scripts/smoke-ai.mjs --run-live` を明示実行した場合だけ、架空のサンプル書類と架空の登録情報を使います。

PDF.js、pdf-lib、React、Electronを使用しています。APIの実行時には [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs) と [画像入力](https://developers.openai.com/api/docs/guides/images-vision) を利用しています。
