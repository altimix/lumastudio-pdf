# 保護されたPDFの編集用コピー

開くパスワードを知っているPDF、閲覧はできるものの編集が制限されたPDF、電子署名済みPDFでは、元ファイルを変更せずに新しい編集用コピーを作れます。パスワードを知らないPDFは開けません。

1. PDFを開きます。開くパスワードが必要なら、画面に入力します。署名済みPDFはまず閲覧専用で表示されるので「編集用コピー」を選びます。
2. コピー作成画面で失われる情報を確認し、「編集用コピーを作成」を押します。
3. 作成された別名のPDFに文字・チェック・印鑑などを追加し、完成版を別名で保存します。

この処理はPDF.jsで**画面に見えるページを描画**し、その画像を新しいPDFの各ページへ配置します。元の検索・選択できる文字、リンク、フォーム欄、暗号化・編集制限、電子署名は新しいコピーに含まれません。小さい文字や拡大印刷は、元のベクターPDFより鮮明さが下がる場合があります。各ページは最大約180dpi相当で作成します。元のページ順と見た目の寸法を保持し、コピーを作る前のPDFはそのまま残します。

元の電子署名はコピーの変更内容を保証しません。提出先が電子署名を求める場合は、新しいコピーを編集後、利用者の証明書で改めて署名してください。元の署名の内容や信頼性は元PDFで確認してください。画像の印鑑だけでは電子署名の代わりにはなりません。

入力したPDFパスワードは画面を閉じると消去し、設定・作業データ・ログには保存しません。PDFやパスワードをOpenAIへ送信しません。コピー作成の上限は元PDF50MB・200ページ・完成コピー50MBです。大きいファイルはページを分けてください。

通常のテストでは架空のPDFとテスト専用パスワードを使い、誤入力、編集制限、署名情報、原本を変更しないこと、作成したPDFの再読み込みと保存を確認します。
