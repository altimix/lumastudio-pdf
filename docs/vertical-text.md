# 縦書きの追記

Issue: https://github.com/altimix/lumastudio-pdf/issues/47

「文字を記入」の書式欄、または配置済みの文字を選択した書式欄で「文字の向き」を選びます。横書きが初期値です。縦書きでは上から下へ入力し、改行で左の列へ進みます。入力中の日本語変換、確定、取り消しは横書きと同じです。

## 保存と互換性

`Annotation.writingMode` は `horizontal-tb` または `vertical-rl` です。省略した既存データは横書きとして扱い、不正な値を読み込んだ場合はエラーにします。作業形式4を使い、向きを認識できない古いアプリでの再保存による喪失を防ぎます。既存の形式1〜3は読み込めます。完成PDFの描画は画面プレビューと同じCanvas処理で、同じ端末の保存PDF再編集情報にも向きを含めます。

## 描画と操作

- `vertical-text.ts` が書記素単位の列分割・寸法・Canvas描画を共有します。結合文字と絵文字の連続を分割せず、CRLFを改行として扱います。
- 句読点と小書き仮名を右上へ配置し、括弧・長音記号等を回転します。英数字は正立します。下線は各列の右に描きます。
- 入力中はCSSの縦書きを使います。確定後と保存PDFは同じCanvas画像です。入力中の字形と確定後の字形にはブラウザー組版による細かな差があります。
- 改行で枠が増える場合は右側の開始列を保ち、左へ広げます。用紙の範囲に制限します。フォント・サイズ変更、移動、拡縮、履歴は既存の編集処理を使います。
- 自動折り返し・禁則処理・ルビ・縦中横は対象外です。用紙に収まらない文字は枠外で切れるため、入力内容に応じて改行や文字サイズを調整します。

## 検証

`vertical-text.test.ts` と作業形式テストで書記素、方向、枠、互換性を確認します。`vertical-text.spec.ts` は入力・方向変更・履歴・再開・PDF保存、および0/90/180/270度の元ページ回転とCropBox付きPDFの画面・保存結果をピクセル比較します。配布スモークテストでも縦書きの作業データと保存PDFの再編集を確認します。
