# LumaStudio PDF v1.0.5

「文字を記入」で新しく置くテキストボックスの縦横比ロックを、初期状態でオフにした更新です。Windows のポータブル EXE と、Apple Silicon・Intel Mac 向け ZIP を配布します。

## 変更内容

- 文字ボックスを置いた直後から、辺や角のハンドルで幅と高さを別々に変えられます。幅・高さの数値入力も独立して使えます。
- 幅を狭めて文字が折り返された場合は、必要な高さを保って文字切れを防ぎます。
- 「縦横比をロック」をオンにすると、文字サイズを含めて比率を保った拡大縮小ができます。作業データにロックの状態と寸法を保存し、再開できます。

## 配布と確認範囲

配布ファイルは Windows の `LumaStudio-PDF-1.0.5-windows-x64-portable.exe`、Mac の `LumaStudio-PDF-1.0.5-macos-arm64.zip` と `LumaStudio-PDF-1.0.5-macos-x64.zip` です。Mac 初回起動の案内、GPL ライセンス、SHA-256 一覧も付けます。Windows は発行元のコード署名がなく、Mac は Apple の公証を行っていません。

Windows・Mac の CI で単体・画面操作テストと配布アプリの起動を架空書類で確認します。文字の初期ロック状態、幅と高さの調整、作業データの再開、折り返した末尾が完成版 PDF に残ることは画面操作テストで確認します。利用者 Mac での初回許可、実プリンター、本番証明書による相手側での信頼表示は個別の確認が必要です。通常の編集とテストで実際の OpenAI API は呼びません。
