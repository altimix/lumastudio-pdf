# LumaStudio PDF v1.0.2

書類の編集操作を見つけやすくした更新です。WindowsのポータブルEXEと、Apple Silicon・Intel Mac向けZIPを配布します。v1.0.1のPDFと作業データを引き続き開けます。

## 変更内容

- 「編集」「表示」メニュー内の項目を日本語にしました。文字入力用の標準操作を残し、PDF編集のUndo・Redo、PDFの表示倍率、ページ一覧の切り替えも選べます。
- 「ファイル」「ページ」「道具」メニューから、PDFの結合・保存・印刷、ページの移動・回転・削除、文字・印鑑・ペンなどの道具を選べます。証明書による署名とAI自動記入は、従来の確認画面を開いてから実行します。
- ページの順序変更・右回転・削除を、PDFのすぐ上に文字付きボタンで配置しました。右側の3段階の案内を除き、何も選んでいないときはページの寸法・向き・回転を表示します。道具や素材を選ぶと同じ場所に設定が現れ、PDFの位置は動きません。

## 配布と確認範囲

配布ファイルはWindowsの`LumaStudio-PDF-1.0.2-windows-x64-portable.exe`、Macの`LumaStudio-PDF-1.0.2-macos-arm64.zip`と`LumaStudio-PDF-1.0.2-macos-x64.zip`です。Mac初回起動の案内、GPLライセンス、SHA-256一覧も付けます。Windowsは発行元のコード署名がなく、MacはAppleの公証を行っていません。

Windows・MacのCIでテスト、メニュー構成、配布パッケージの起動とPDF操作を確認します。Macの利用者環境での初回許可、実プリンター、本番証明書による相手側での信頼表示は個別の確認が必要です。通常の編集とテストで実際のOpenAI APIは呼びません。
