# LumaStudio PDF v1.0.7

PDFの読み込み容量制限を取り除き、保存したPDFを同じ端末で開き直して編集を続けられる更新です。WindowsのポータブルEXEと、Apple Silicon・Intel Mac向けZIPを配布します。

## 変更内容

- 通常のPDF読み込み、複数PDFの結合、印刷受信箱からの取り込み、保護PDFからの編集用コピーについて、固定のファイル容量上限を撤廃しました。扱える大きさは端末のメモリ・ディスク容量に左右されます。ページ数は200ページ、1回の結合は30ファイルまでです。
- デスクトップ版でこの版から保存した未署名PDFは、同じインストール環境で開くと文字・チェック・印影などを再編集できます。保存済みPDFそのもののハッシュと照合したときだけ編集情報を読み込みます。外部アプリでPDFが変わった場合や別の端末では完成ページとして開きます。
- 再編集に必要な元PDFと編集情報は端末のアプリデータ領域へ保存します。元PDFは同一内容ごとに1個だけ保管します。この領域は暗号化保管庫ではありません。別端末へ編集を移すときは、従来どおり `.lumapdf` の作業データを保存してください。
- 元PDFや既存ファイルは上書きせず、完成した一時ファイルから新しい名前で保存します。署名済みPDFの閲覧専用は維持します。

`.lumapdf` の作業データには別の100MB上限があります。追加した要素は完成PDF上で画像として固定され、他のPDFアプリで個別編集はできません。

## 配布と確認範囲

配布ファイルは `LumaStudio-PDF-1.0.7-windows-x64-portable.exe`、`LumaStudio-PDF-1.0.7-macos-arm64.zip`、`LumaStudio-PDF-1.0.7-macos-x64.zip` です。Mac初回起動の案内、GPLライセンス、SHA-256一覧を付けます。Windowsは発行元のコード署名がなく、MacはAppleの公証を行っていません。

Windows・MacのCIで単体テスト、画面操作テスト、配布アプリの起動と保存PDFの再編集を確認します。利用者環境での非常に大きなPDF、実プリンター、本番証明書、OSによる初回起動許可は個別の確認が必要です。通常の編集とテストで実際のOpenAI APIは呼びません。
