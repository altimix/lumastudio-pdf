# LumaStudio PDF v1.0.6

左のページ一覧へ別のPDFをドラッグ＆ドロップし、指定位置に直接結合できる更新です。Windows のポータブル EXE と、Apple Silicon・Intel Mac 向け ZIP を配布します。

## 変更内容

- 開いているPDFのサムネイル一覧へ1個または複数のPDFをドロップすると、緑の挿入線で示した位置に全ページを追加します。複数ファイルはドロップされたファイル順に入り、結合画面を経由しません。
- 既存ページ、記入済みの文字や印鑑、編集可能な作業データを保ちます。結合は1回の「元に戻す」で取り消し、「やり直す」で復元できます。完成PDFにも指定したページ順を反映します。
- サムネイル内での既存ページの並べ替えと、上部「PDFを結合」で順番を調整して末尾へ追加する操作も使えます。不正なPDFを含むドロップは一括拒否し、署名付きPDFの閲覧専用は維持します。

## 配布と確認範囲

配布ファイルは Windows の `LumaStudio-PDF-1.0.6-windows-x64-portable.exe`、Mac の `LumaStudio-PDF-1.0.6-macos-arm64.zip` と `LumaStudio-PDF-1.0.6-macos-x64.zip` です。Mac 初回起動の案内、GPL ライセンス、SHA-256 一覧も付けます。Windows は発行元のコード署名がなく、Mac は Apple の公証を行っていません。

Windows・Mac の CI で単体テスト、架空PDFを使った画面操作テスト、配布アプリの起動を確認します。画面操作テストではファイルドロップを再現し、挿入順、元の書き込み、取り消し・やり直し、完成PDF、作業データの再開、不正ファイルと署名付きPDFの拒否を確認します。実際のOSからのファイルドラッグ操作、利用者Macでの初回許可、実プリンター、本番証明書による相手側での信頼表示は個別の確認が必要です。通常の編集とテストで実際の OpenAI API は呼びません。
