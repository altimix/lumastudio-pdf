# LumaStudio PDF v1.0.8

文字の追記に縦書きを追加しました。Windows用ポータブルEXE、Apple Silicon・Intel Mac用ZIPを配布します。

## 変更内容

- 「文字の向き」で横書き・縦書きを選べます。配置済みの文字も切り替えられ、PDF上で直接入力・再編集できます。
- 縦書きは上から下へ、改行で右の列から左の列へ進みます。句読点・小書き仮名・括弧・長音記号の配置を調整し、英数字は一文字ずつ正立させます。書体・太字・斜体・下線も利用できます。
- 画面と保存PDFで同じ描画処理を使い、ページの回転とCropBoxを保ちます。保存したPDFを同じ端末で再編集するときも文字の向きを復元します。
- 作業データ（.lumapdf）の形式をバージョン4に更新しました。以前の形式1〜3は引き続き開けます。この版で保存した作業データはv1.0.8以降で開いてください。完成PDFは従来どおり一般のPDFビューアーで閲覧できます。

## 利用上の範囲

縦書きの自動折り返し、禁則処理、ルビ、縦中横には対応していません。用紙に収まらない長文は改行・文字サイズ・位置を調整し、保存結果を確認してください。元PDFの本文を書き換える機能ではありません。

Windows版は発行元のコード署名がなく、Mac版はアドホック署名です。Appleの公証は受けていません。Macの初回起動は同梱の `README-Mac.txt` を参照してください。配布物のライセンスはGPL-3.0-onlyです。
