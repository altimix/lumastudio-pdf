# LumaStudio PDF v0.2.0 試用版

PDFに直接記入し、2本指で拡大して、文字・印鑑・画像のサイズを用紙上で調整できるようにしました。

## 新しい操作

- **ピンチズーム**：トラックパッド／タッチ画面の2本指で20〜400%に拡大縮小。指やカーソル付近を見ながら拡大できます。Ctrl＋ホイールにも対応します。
- **直接入力**：「文字を記入」を選んで用紙をクリックすると、その場で日本語・複数行の文章を入力できます。追加した文字はダブルクリックまたはEnterで再編集できます。
- **黒を初期色に**：手入力とAI自動記入の文字色の初期値をRGB（0, 0, 0）にしました。既存の作業データで指定済みの色はそのまま復元します。
- **四隅でサイズ変更**：素材を選択してハンドルをドラッグ。文字は文字サイズも変わり、印鑑・画像は縦横比を保ちます。回転したページにも対応します。
- **表示位置の移動**：「手のひら・スクロール」、Space＋ドラッグ、中ボタンドラッグで用紙を移動できます。「ページ全体に合わせる」も追加しました。
- **細かい位置調整**：選択した素材は矢印キーで1ポイント、Shift＋矢印キーで10ポイント移動できます。

直接入力はEnterで改行、**完了** または **Ctrl / ⌘ + Enter** で確定、Escで取り消します。日本語変換中のキー操作は変換を優先します。直接入力やドラッグによる修正は1回の「元に戻す」で取り消せます。PDF保存・作業データ保存・印刷にも編集中の文字を反映します。

完成したPDFは「PDFを保存」から別名で書き出してください。あとから追加文字や印鑑を修正する場合は、あわせて「作業データ」を保存してください。元のPDFの既存本文を書き換える機能、OCRは含みません。

## ダウンロード

| 利用環境 | ファイル |
| --- | --- |
| Windows 64bit | `LumaStudio-PDF-0.2.0-windows-x64-setup.exe` |
| Windows・インストールなし | `LumaStudio-PDF-0.2.0-windows-x64-portable.exe` |
| Apple Silicon Mac | `LumaStudio-PDF-0.2.0-macos-arm64.dmg` |
| Intel Mac | `LumaStudio-PDF-0.2.0-macos-x64.dmg` |

Mac用ZIP、初回起動案内 `README-Mac.txt`、SHA-256一覧も添付しています。Node.jsのインストールは不要です。

Mac版はアドホック署名を使い、Developer ID署名・Apple公証はありません。Applicationsへ移したあと開発元の確認警告が出る場合は、配布元を確認し **システム設定 → プライバシーとセキュリティ → このまま開く** でアプリを個別に許可します。[Apple公式手順](https://support.apple.com/ja-jp/guide/mac-help/mh40616/mac)。Windows版も発行元によるコード署名はありません。

## 検証範囲

CIではWindows・macOSの単体テスト、ブラウザー操作テスト、パッケージ作成・起動・PDF表示を確認します。ズームとタッチはブラウザーの入力イベントによる検証で、利用者の実トラックパッドやタッチパネル、Macの初回許可画面、実プリンターは別途確認が必要です。

通常編集は端末内で行い、AIは利用者が明示実行した場合だけページ画像と登録情報を送信します。APIキーや個人の書類・印鑑・証明書を配布物に含めません。署名済みPDFは引き続き閲覧専用です。証明書署名の対応形式・制限はアプリの「証明書ガイド」とREADMEを参照してください。
