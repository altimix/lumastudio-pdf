# LumaStudio PDF v0.3.2 試用版

AI自動記入に使うモデルを **GPT-6 Sol** と **GPT-6 Luna** から選べるようにしました。初期値はSolです。AI設定画面の「利用モデル」で選び、APIキーを保存済みならキーを入力し直さずに変更できます。

## 変更点

- Solを初期モデルとし、Lunaを選択肢に追加。選んだモデルは次回起動後も使われます。
- `.env` のAPIキーを使う場合も、モデルの選択だけを端末へ保存できます。
- 以前の設定に未対応のモデル名が保存されている場合は、暗号化されたキーを保持してSolへ切り替えます。新たな設定にはSol/Luna以外を保存できません。
- AIへの送信は、利用者が自動記入を実行した場合だけです。選択したモデルをResponses APIへ渡し、画像入力、JSON Schema、`store: false` と返答内容の検証を維持しています。

SolとLunaの利用可否やAPI料金は利用者のOpenAIアカウントによります。モデルの公式説明: [GPT-6 Sol](https://developers.openai.com/api/docs/models/gpt-6-sol)、[GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)。通常のPDF編集・押印・保存にAPIキーは必要ありません。

## ダウンロードと確認範囲

Windowsのインストーラー／ポータブル版、Apple Silicon・Intel MacのDMG／ZIP、Macの起動案内、GNU GPL v3の原文、SHA-256一覧を配布します。Node.jsのインストールは不要です。

Windowsは発行元によるコード署名、MacはDeveloper ID署名・Apple公証をまだ行っていません。Macの初回起動は`README-Mac.txt`で案内します。[Apple公式の初回許可手順](https://support.apple.com/ja-jp/guide/mac-help/mh40616/mac)

Windows・MacのCIで単体テスト、ブラウザー操作、配布パッケージの内容・起動を確認します。通常テストは架空のキーと書類を使用し、実APIへの通信や実文書の認識精度を検証するものではありません。利用者の実トラックパッド、Macの初回許可、実プリンター、本番証明書の受取側表示も別途確認が必要です。
