# LumaStudio PDF v1.0.3

保存・押印・ヘルプを使いやすくした更新です。WindowsのポータブルEXEと、Apple Silicon・Intel Mac向けZIPを配布します。v1.0.2以前のPDFと作業データを引き続き開けます。

## 変更内容

- WindowsのCtrl+S、Macの⌘Sから完成したPDFを別名で保存できます。メニューの「ファイル」→「PDFを保存」にもショートカットを表示します。文字の入力途中でも現在の内容を反映します。
- 名前から作る印鑑と登録した画像印鑑を、クリック位置が素材の中心になるように配置します。用紙の端では、はみ出さない位置に収めます。
- 未保存のまま閉じる際に「編集を続ける」「PDFを保存して終了」「作業データを保存して終了」「変更を破棄して終了」から選べます。保存を取り消したり失敗したりした場合はアプリを閉じず、編集内容を保持します。
- 「ヘルプ」メニューから日本語の使い方マニュアルとショートカット一覧をオフラインで読めます。現在の版数も表示し、「最新版・更新履歴を見る」を選ぶと公開ページを開きます。ポータブル版の更新は手動です。

## 配布と確認範囲

配布ファイルはWindowsの`LumaStudio-PDF-1.0.3-windows-x64-portable.exe`、Macの`LumaStudio-PDF-1.0.3-macos-arm64.zip`と`LumaStudio-PDF-1.0.3-macos-x64.zip`です。Mac初回起動の案内、GPLライセンス、SHA-256一覧も付けます。Windowsは発行元のコード署名がなく、MacはAppleの公証を行っていません。

Windows・MacのCIで単体・画面操作テストと、配布アプリのCtrl／⌘+S、保存して終了、ヘルプ表示を架空書類で確認します。利用者Macでの初回許可、実プリンター、本番証明書による相手側での信頼表示は個別の確認が必要です。通常の編集とテストで実際のOpenAI APIは呼びません。
