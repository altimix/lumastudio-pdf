# LumaStudio PDF v1.0.1

PDFの表示と書き込み操作を改善した正式公開版です。WindowsのポータブルEXEと、Apple Silicon・Intel Mac向けZIPを配布します。v1.0.0で保存したPDFと作業データを引き続き開けます。

## 変更内容

- 最大化・全画面表示中は、アプリ上部に「元のサイズに戻す」を表示します。Escキーまたは「表示」メニューからも通常サイズへ戻せます。文字入力やダイアログ内のEsc操作を妨げません。
- 左のページサムネイルを、元PDFの用紙寸法とアプリ内の回転に合わせて表示します。縦・横・正方形が混在するPDFや、もともと回転情報を持つPDFでも形と内容が枠内に収まります。
- ペンで手書きし、Shiftを押したまま引くと直線を描けます。蛍光ペンは半透明です。描いた線は移動・サイズ変更、Undo、作業データへの保存と再開に対応します。消しゴムはペン・蛍光ペンの線だけを線ごと削除し、元PDF本文や文字・印鑑・画像には作用しません。

v1.0.1で手書き素材を含めた作業データは、新しい種類を知らないv1.0.0では開けません。編集を再開する際はv1.0.1以降をお使いください。完成したPDFは通常のPDFビューアーで開けます。

## 配布と確認範囲

配布ファイルはWindowsの`LumaStudio-PDF-1.0.1-windows-x64-portable.exe`、Macの`LumaStudio-PDF-1.0.1-macos-arm64.zip`と`LumaStudio-PDF-1.0.1-macos-x64.zip`です。Mac初回起動の案内、GPLライセンス、SHA-256一覧も付けます。Windowsは発行元のコード署名がなく、MacはAppleの公証を行っていません。

Windows・MacのCIで単体テスト、ブラウザー操作、配布パッケージの内容・起動を確認します。最大化・全画面からの復帰、縦横混在PDF、手書き・直線・マーカー・消しゴムを架空データで検証します。利用者のMac初回許可、実プリンター、本番証明書の相手側での信頼表示は個別の確認が必要です。
