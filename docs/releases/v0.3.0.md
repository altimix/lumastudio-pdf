# LumaStudio PDF v0.3.0 試用版

日本語フォントと文字装飾、直接入力・横ドラッグで使える数値欄、図形の編集を追加しました。

## 初期設定

- 文字：Noto Sans JP、11pt、黒（RGB 0, 0, 0）。
- 印鑑：35×35pt。画像の印影は縦横比を保って35pt四方に収めます。
- チェック：12×12pt。

## 新しい操作

- **書体選択**：Google Fontsで提供されるNoto Sans JP、Noto Serif JP、M PLUS 1、BIZ UDGothicを同梱しました。オフラインで使え、編集中の文字を外部のフォント配信先へ送信しません。
- **文字装飾**：太字・斜体・下線を選択。画面と保存PDFで同じ描画を使います。斜体は合成斜体です。
- **数値の直接入力**：文字サイズなどを空欄にして打ち直せます。Enterまたは欄外へ移動して確定、Escで取消。入力中に最小値6へ戻る問題を修正しました。
- **数値の横ドラッグ**：数値欄の上を左右にドラッグして調整。Shiftで大きく、Altで細かく変化し、1回の「元に戻す」で取り消せます。
- **図形**：長方形・楕円／円・三角形を配置し、枠線と塗りつぶしの色・表示の有無・枠線幅を指定。四隅・四辺のハンドルで縦横を自由に変えられます。

## 作業データとフォント

旧作業データも読み込めます。旧文字の書体は「従来のシステムフォント（互換）」として保持します。新たに保存する`.lumapdf`は形式バージョン2で、v0.3.0以降で開いてください。通常のPDF出力は、受け取る側のフォント環境に依存しません。

フォントのライセンスと著作権表示はアプリに同梱しています。詳しくは`docs/fonts.md`を参照してください。

## ダウンロードと確認範囲

Windowsのインストーラー／ポータブル版、Apple Silicon・Intel MacのDMG／ZIP、Macの起動案内、SHA-256一覧を配布します。Node.jsのインストールは不要です。

Windowsは発行元によるコード署名、MacはDeveloper ID署名・Apple公証をまだ行っていません。Macはアドホック署名で整合性を検査し、初回起動方法は`README-Mac.txt`に同梱しています。[Apple公式の初回許可手順](https://support.apple.com/ja-jp/guide/mac-help/mh40616/mac)

Windows・MacのCIで単体テスト・ブラウザー操作・配布パッケージ作成・起動を確認します。配布アプリ内でのNoto Sans JPのローカル読み込みと図形操作も検証します。利用者の実トラックパッド・タッチパネル、Macの初回許可、実プリンター、本番証明書の受取側での信頼表示は別途確認が必要です。

基本編集は端末内で行い、AIは利用者が明示実行した場合にだけ文書情報を送信します。APIキー、個人の書類・印鑑・証明書は配布物に含めません。既存PDF本文の書き換え、OCRは対象外で、署名済みPDFは閲覧専用です。
