# LumaStudio PDF v0.3.1 試用版

v0.3.0の編集機能を維持したまま、ソースコードと配布物を GPL-3.0-only で公開するための版です。配布アプリ内にGNU GPL v3のライセンス全文を同梱し、MacのDMG・ZIPとこのリリースにもライセンスファイルを添えています。公式サイトは [lumastudiopdf.altimix.jp](https://lumastudiopdf.altimix.jp/) です。

## 前の版からの変更

- Windowsのインストーラー／ポータブル版とMacのDMG／ZIPに、GPLのライセンス本文を含めました。
- リリースに `LICENSE.txt` を追加し、配布ファイルのSHA-256一覧にも含めました。
- 配布物内のライセンス本文がリポジトリの `LICENSE` と一致することを、Windows・Macのパッケージ検査で確認します。
- 公式サイトから、対応するOSの配布ファイル、Macの初回起動案内、チェックサム、ライセンスへ直接進めます。

日本語フォント、印鑑サイズの記憶、PDF上の直接入力、ページ整理、図形編集などの操作はv0.3.0と同じです。機能の詳細は [v0.3.0の説明](v0.3.0.md) を参照してください。旧作業データを読み込め、新しく保存する作業データは形式バージョン2です。

## ダウンロードと確認範囲

Windowsのインストーラー／ポータブル版、Apple Silicon・Intel MacのDMG／ZIP、Macの起動案内、GNU GPL v3の原文、SHA-256一覧を配布します。Node.jsのインストールは不要です。

Windowsは発行元によるコード署名、MacはDeveloper ID署名・Apple公証をまだ行っていません。Macはアドホック署名で整合性を検査し、初回起動方法は`README-Mac.txt`で案内します。[Apple公式の初回許可手順](https://support.apple.com/ja-jp/guide/mac-help/mh40616/mac)

Windows・MacのCIで単体テスト、ブラウザー操作、実際の配布パッケージの内容・起動を確認します。利用者の実トラックパッド・タッチパネル、Macの初回許可、実プリンター、本番証明書の受取側での信頼表示は別途確認が必要です。

基本編集は端末内で行い、AIは利用者が明示実行した場合にだけ文書情報を送信します。APIキー、個人の書類・印鑑・証明書は配布物に含めません。既存PDF本文の書き換え、OCRは対象外で、署名済みPDFは閲覧専用です。
