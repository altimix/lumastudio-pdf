# LumaStudio PDF v1.0.0

メールで届いたPDFに記入・押印して返送するための、Windows・Mac向け正式公開版です。元PDFを残して追加加工し、結合・並べ替え・ページ削除・別名保存まで一つの画面で行えます。ソースコードはGPL-3.0-onlyで公開しています。

## この版の追加内容

- 開くパスワードが分かるPDF、閲覧できる編集制限付きPDF、署名済みPDFの表示から、新しい編集用コピーを作れます。パスワードは保存・外部送信しません。署名済みPDFは原本を閲覧専用のまま保ちます。
- 編集用コピーは表示を画像化した新しいPDFです。元の文字検索・選択、リンク、フォーム欄、暗号化・編集制限、電子署名は引き継がれません。元PDF50MB、200ページ、完成コピー50MBまで。XFA専用フォームと開くパスワード不明のPDFには対応しません。
- チェックの初期サイズを15×15ptにし、チェックと図形はクリック位置を中心に配置します。文字は縦方向の中心をクリック位置に合わせ、左端はクリック位置に置きます。
- 文字・印鑑・画像・チェック・図形に縦横比ロックのオン／オフを追加しました。丸を図形の初期値とし、線・二重線（取消線）も使えます。
- AI記入でGPT-6 SolとGPT-6 Lunaを選べます。初期値はGPT-6 Solです。AIは利用者が明示したときだけ送信され、別途APIキーと利用料が必要です。

## ダウンロード

| OS | 配布ファイル | 使い方 |
| --- | --- | --- |
| Windows 64bit | `LumaStudio-PDF-1.0.0-windows-x64-portable.exe` | ダウンロードしたEXEを起動。インストール不要 |
| Mac Apple Silicon | `LumaStudio-PDF-1.0.0-macos-arm64.zip` | ZIPを展開し、アプリを「アプリケーション」へ移動 |
| Mac Intel | `LumaStudio-PDF-1.0.0-macos-x64.zip` | ZIPを展開し、アプリを「アプリケーション」へ移動 |

WindowsのインストーラーとMacのDMGは配布しません。更新は手動です。設定はOSの利用者データ領域に保存され、アプリ本体を削除しても自動では消えません。配布ファイルと案内・ライセンスのSHA-256は`SHA256SUMS.txt`で確認できます。

## 安全性と確認範囲

通常の記入・押印・保存は端末内で処理します。画像の印鑑は見た目の押印であり、改変検出にはご自身のP12／PFX証明書による電子署名が必要です。OpenAI APIキーから証明書を自動取得する機能はありません。

Windowsは発行元のコード署名がなく、MacはDeveloper ID署名とApple公証を行っていません。Macには整合性確認用のアドホック署名を付けています。初回の個別許可は同梱の`README-Mac.txt`をご覧ください。[Apple公式の起動許可手順](https://support.apple.com/ja-jp/guide/mac-help/mh40616/mac)

Windows・MacのCIで単体テスト、ブラウザー操作、配布パッケージの内容・起動を確認します。テストには架空文書・テスト用のパスワードと証明書を使います。利用者の実文書、実プリンター、Macの初回許可画面、本番証明書の相手側での信頼表示は個別の確認が必要です。
