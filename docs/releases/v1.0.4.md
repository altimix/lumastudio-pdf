# LumaStudio PDF v1.0.4

蛍光ペンの端の形を選べるようにし、図形をドラッグした大きさで配置できるようにした更新です。Windows のポータブル EXE と、Apple Silicon・Intel Mac 向け ZIP を配布します。

## 変更内容

- 蛍光ペンの端を「角」「丸」から選べます。初期値は「角」です。描いた線を選択してから端の形を変更することもできます。
- 長方形、楕円・円、三角形、線、二重線（取消線）の5種類を、用紙上でドラッグした大きさと向きで配置できます。クリックのみの場合は従来の大きさで配置します。配置後も位置や大きさを調整できます。
- これらの編集内容は作業データと完成版 PDF に保存できます。アプリ内のヘルプにも操作方法を追加しました。

## 配布と確認範囲

配布ファイルは Windows の `LumaStudio-PDF-1.0.4-windows-x64-portable.exe`、Mac の `LumaStudio-PDF-1.0.4-macos-arm64.zip` と `LumaStudio-PDF-1.0.4-macos-x64.zip` です。Mac 初回起動の案内、GPL ライセンス、SHA-256 一覧も付けます。Windows は発行元のコード署名がなく、Mac は Apple の公証を行っていません。

Windows・Mac の CI で単体・画面操作テストと配布アプリの起動を架空書類で確認します。蛍光ペンと図形の配置、作業データの再開、完成版 PDF への反映は画面操作テストで確認します。利用者 Mac での初回許可、実プリンター、本番証明書による相手側での信頼表示は個別の確認が必要です。通常の編集とテストで実際の OpenAI API は呼びません。
