# LumaStudio PDF v1.0.9

追記の重なり表示と、電子署名後の編集用原稿の保存を改善しました。Windows用ポータブルEXE、Apple Silicon・Intel Mac用ZIPを配布します。

## 変更内容

- 文字・画像・図形などを選択しても、追記の重なり順を保つように修正しました。選択枠とサイズ変更のハンドルを表示しながら、編集画面と保存PDFの見え方を揃えます。消しゴムで線を消す途中も、ほかの追記との重なりを維持します。
- 電子署名付きPDFを保存した後も、未保存の編集用原稿を保護します。「編集用原稿を保存」の案内から作業データ（`.lumapdf`）を保存でき、保存せずに閉じたり別の書類を開いたりする場合は変更を確認します。
- 保存・再編集のマニュアルに、署名付きPDFと編集用原稿をそれぞれ保存する手順を追加しました。

## 利用上の範囲

署名済みPDFは引き続き閲覧専用です。あとで修正する場合は、署名前の原稿を保存しておいてください。印影画像による押印と証明書による電子署名は別の機能です。

作業データの形式はv1.0.8と同じ形式4です。以前の形式1〜3も開けます。未署名PDFから編集を再開できるのは、同じインストール環境で保存・再読み込みした場合です。別の端末へ原稿を移すときは `.lumapdf` も保存してください。

Windows版は発行元のコード署名がなく、Mac版はアドホック署名です。Appleの公証は受けていません。Macの初回起動は同梱の `README-Mac.txt` を参照してください。配布物のライセンスはGPL-3.0-onlyです。
