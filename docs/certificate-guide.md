# はじめての署名用証明書

LumaStudio PDFでは、印影画像の貼り付けと、証明書を使う電子署名を別々に利用できます。印影画像は見た目の印鑑です。電子署名には、署名者の情報を示す電子証明書と、本人が署名に使う「秘密鍵」が必要です。

アプリの「署名して保存」画面にある **「証明書を持っていない方へ」** から、同じ手順を確認できます。証明書を持っていなくても、PDFの編集・印影の配置・通常の保存は利用できます。

## 1. 取得する前に、提出先へ確認

銀行・取引先などに、次の内容を確認します。

- PDFへの電子署名で提出できるか。
- 指定の証明書、署名サービス、タイムスタンプなどの条件があるか。
- 個人名で署名するのか、会社・法人の代表者として署名するのか。

証明書を買えばどの書類にも使えるわけではありません。提出先が特定のサービスを指定している場合は、その案内を優先します。

## 2. 自分に合う取得先を選ぶ

### 個人・個人事業主の場合

本人確認を行う認証事業者に相談します。国内の個人向けの例として、[セコムパスポート for G-ID](https://www.secomtrust.net/service/ninsyo/forgid.html)があります。公式サイトではファイル形式での提供が案内され、[一般向けFAQ](https://www.secomtrust.net/service/ninsyo/gfaq.html)ではPKCS#12ファイルの扱いを確認できます。

この掲載は取得先の例です。本アプリと、その事業者が実際に発行した証明書との互換性を確認済みという意味ではありません。取得前に、PDF文書への署名に利用できる契約・用途か、秘密鍵を含むファイルを取得できるか、提出先が受理するかを確認してください。

セコムの[公式利用環境](https://www.secomtrust.net/service/ninsyo/gsyo.html)はWindowsを対象としています。Macを使う方は、取得方法と利用条件を申請前に確認してください。本アプリはWindows／Macの両方でP12／PFX形式を扱いますが、取得先のOSサポート条件は別に確認する必要があります。

### 会社・法人の代表者の場合

商業・法人登記に基づく代表者の電子証明書は、[法務省のファイル形式の案内](https://www.moj.go.jp/MINJI/minji06_00256.html)と[取得手順](https://www.moj.go.jp/MINJI/minji06_00086)を確認します。[法務省FAQ](https://www.moj.go.jp/MINJI/minji06_00034.html)にも、電子証明書と秘密鍵の取得・管理に関する案内があります。

本アプリが対応するのは **ファイル形式の証明書** です。商業登記リモート署名には対応していません。制度・ソフトウェア・申請手順は変わるため、申請時の公式案内に従ってください。Macで本アプリを使う場合も、証明書の取得作業で使えるOSを取得先へ確認します。

## 3. 必要な形式を伝えて申し込む

必要なのは、**署名用の秘密鍵を含む `.p12` / `.pfx`（PKCS#12）ファイル** です。鍵の形式はRSA 2048ビット以上、利用者の署名用証明書1つと対応する秘密鍵1つを使用します。関連する中間証明書を同じファイルに含めることはできます。

`.cer` / `.crt`の証明書だけでは署名できません。マイナンバーカード・ICカード・USBトークン・クラウド署名・OS証明書ストアからの直接利用も、このバージョンでは未対応です。

取得先への問い合わせに、そのまま使える文章です。

> PDF文書への電子署名に利用する証明書を探しています。
> RSA 2048ビット以上で、署名用の秘密鍵を含むP12／PFX（PKCS#12）ファイルを取得できますか。
> PDF文書への署名に利用できる契約・用途か、Windows／Macでの取得方法、本人確認に必要な書類と費用・所要日数を教えてください。
> 受取先が受け付ける証明書の種類や、Adobe Acrobatでの信頼設定についても確認したいです。
> 使用するアプリはLumaStudio PDFです。ICカード・USBトークン・クラウド署名・タイムスタンプには未対応です。

本人確認書類、料金、発行までの日数は取得先・証明書の種類で異なります。公式サイトで確認して申し込み、審査と発行の案内に従ってください。このアプリ内で購入や本人確認を行う機能はありません。

## 4. 証明書ファイルとパスワードを保管

証明書ファイルは自分だけが使える場所に保存し、パスワードは別に保管します。取得先のバックアップ・失効手順も確認してください。ファイルやパスワードの漏えい・紛失があれば、発行元へ相談します。

**メール返送時に添付するのは完成したPDFだけです。** 証明書ファイル、秘密鍵、パスワードは受取人へ渡しません。

## 5. LumaStudio PDFで読み込んで署名

1. Windows／Macのデスクトップ版で、PDFへの文字入力と押印を終えます。
2. 後から修正できるように「作業データ」を保存します。
3. 「署名して保存」→「証明書ファイルを選ぶ」でP12／PFXを開きます。
4. パスワードを入力して「証明書を確認」を押します。
5. 署名者、発行者、有効期間を確認します。
6. 「電子署名してPDFを保存」を押し、別のファイルとして保存します。
7. 完成したPDFをAdobe Acrobatなどで開き、署名を確認して返送します。[Adobe公式の確認方法](https://helpx.adobe.com/acrobat/desktop/e-sign-documents/manage-digital-signatures/validate-digital-sign.html)

署名後のPDFを直すときは、署名前の作業データを開いて編集し直し、もう一度署名してください。

アプリで「証明書を読み込みました」と表示されるのは、ファイルと秘密鍵などを読み込んで確認できたという意味です。発行者への信頼、失効状況、提出先での受理まで保証するものではありません。自己署名のテスト証明書は、第三者による本人確認を受けた証明書とは異なります。

現在はタイムスタンプと長期検証に未対応です。詳しい技術的な対応範囲は[電子署名の説明](./signatures.md)を参照してください。
