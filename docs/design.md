# LumaStudio PDF MVP design

目的は、届いた書類に記入・押印して返送できること。最初から編集の道具が見えるデスクトップの作業机にする。

- 色: paper #ffffff、workspace #e9eef0、ink #233b40、green #235d59、line #d9e1e4、stamp #bb373c。
- 文字: UIは Windows の Yu Gothic UI と macOS の Hiragino Sans。書類への追加文字は Yu Gothic / Hiragino Kaku Gothic ProN、印鑑は明朝系。製品名のみ Georgia の字形で静かな個性を出す。
- 配置: 上にファイル操作、左にページ一覧、中央に実寸比の用紙、右に選択した道具の設定。説明は左揃え。小さい画面では右の設定を下に置く。
- 主役は白い用紙と朱色の印鑑。装飾カードや宣伝用のヒーローは置かない。何を入力して、どこへ置くかを明示する。
- 初期画面にはPDFを開く操作と架空の振込先届出書サンプルだけを示す。書類を開く前から実際のツールバーを使える構造を見せる。

見直し: 汎用ダッシュボードのようなカード群を避け、用紙の縦横比と実際のページナビゲーションで構成する。アクセントをすべてに使わず、保存ボタンと選択中の道具に限定する。
